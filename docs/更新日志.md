| 项目 | 内容 |
|------|------|
| 更新时间 | 2026-02-27 |
| 更新内容 | 实现完善的日志分级功能，支持多目标输出和日志轮转 |
| 影响范围 | src/utils/logger.py, src/config/settings.py, src/ui/main_window.py, src/core/ |
| 实施人员 | AI助手 |

**重构详情：**
- 新增日志管理模块 `src/utils/logger.py`
- 实现六级日志体系：DEBUG、INFO、SUCCESS、WARNING、ERROR、FATAL
- 实现三种日志处理器：
  - `ConsoleHandler`：控制台彩色输出

- 日志轮转机制：单文件最大10MB，保留5个备份
- 配置化日志级别：可在 `settings.py` 中配置各级别阈值
- 重构现有模块日志调用：
  - `daily_tasks.py`：使用新日志系统
  - `helpers.py`：使用新日志系统
  - `main_window.py`：集成日志管理器
- 新增测试脚本 `tests/test_logger.py`

## [1.0.0] - 2026-02-26

### 新增

#### 核心功能
- ✅ 主界面框架 (`UI.py`)
  - 功能导航栏（日常任务、副本任务、挂机任务、其他功能）
  - 任务配置区（支持多任务勾选）
  - 运行控制区（窗口选择、操作按钮、运行日志）
- ✅ 窗口绑定功能 (`window_picker.py`)
  - 瞄准镜样式按钮，支持长按拖拽识别
  - 自动调整游戏窗口至指定分辨率 (960×540)
  - 区域截图预览功能
- ✅ 后台执行线程 (`ScriptWorker`)

  - 支持任务暂停功能
  - 实时日志输出

#### 日常任务
- ✅ 每日一卦 (`task_gua`)

  - 自动进行卜卦操作
  - 自动接受卦象奖励
- ✅ 课业任务 (`task_keye`)

- ✅ 帮派任务 (`task_bangpai`)

  - 自动进入茶馆

  - 自动退出茶馆

## 版本说明

### 版本号格式
遵循语义化版本规范 `主版本号.次版本号.修订号`

- **主版本号**：不兼容的API修改
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

### 变更类型

| 类型 | 说明 |
|-----|------|
| 新增 | 新功能 |
| 变更 | 现有功能的变更 |
| 弃用 | 即将删除的功能 |
| 移除 | 已删除的功能 |
| 修复 | Bug修复 |
| 安全 | 安全相关修复 |
