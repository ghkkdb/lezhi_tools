## 模块说明

### 1. 入口层 (`main.py`)

程序启动入口，负责初始化 QApplication 并加载主窗口。

```python
# 启动流程
main() → QApplication → ClassicScriptUI → show()
```

### 2. 配置层 (`src/config/`)

| 文件 | 功能 |
|------|------|
| `settings.py` | 定义全局配置项、常量、路径设置 |

### 3. 核心层 (`src/core/`)

| 文件 | 功能 |
|------|------|
| `controller.py` | 任务控制器，管理任务暂停、继续、停止状态 |
| `daily_tasks.py` | 日常任务自动化逻辑，包含任务识别与执行 |
| `helpers.py` | 通用辅助函数，如延时、坐标转换等 |
| `test_dome.py` | 测试示例代码 |

### 4. 界面层 (`src/ui/`)

| 文件 | 功能 |
|------|------|
| `main_window.py` | 主窗口界面，包含所有功能按钮与状态显示 |
| `widgets/crosshair_button.py` | 十字准星选择按钮控件 |
| `widgets/unbind_button.py` | 解绑窗口按钮控件 |
| `widgets/window_picker.py` | 窗口选择器控件 |

### 5. 工具层 (`src/utils/`)

| 文件 | 功能 |
|------|------|
| `image_utils.py` | 图像识别、模板匹配、截图处理 |
| `input_tracker.py` | 输入状态追踪，键盘/鼠标按下状态管理 |
| `logger.py` | 日志记录与管理 |
| `win_api.py` | Windows API 封装，窗口操作、鼠标键盘模拟 |

### 6. 测试层 (`tests/`)

| 文件 | 功能 |
|------|------|
| `dome.py` | 测试示例 |
| `test_logger.py` | 日志模块测试 |

## 资源文件说明

### 图像资源分类

| 目录 | 用途 | 图像数量 |
|------|------|----------|
| `assets/img/chushihua_/` | 初始化任务识别 | 21 个 |
| `assets/img/mengjing_img/` | 梦境任务识别 | 5 个 |
| `assets/img/richang_/` | 日常任务识别 | ~46 个 |
| `assets/img/richang_/shanheqi/` | 山河器任务 | 7 个 |
| `assets/img/richang_/yaoqianshu/` | 摇钱树任务 | 3 个 |

### 图像命名规范

- `M_` 前缀：每日任务相关
- `keye_` 前缀：客夜任务相关
- `bprw_` 前缀：帮派任务相关
- `chaguan_` 前缀：茶馆任务相关
- `_qw` 后缀：确认按钮
- `_tc` 后缀：退出/关闭按钮

## 开发环境配置

### 环境要求

- Python 3.10
- Conda 虚拟环境：`ymjh_venv`

### 安装依赖

```bash
conda create -n ymjh_venv python=3.10
conda activate ymjh_venv
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 主要依赖库

| 库名 | 版本 | 用途 |
|------|------|------|
| PyQt5 | >=5.15.0 | GUI 框架 |
| opencv-python | >=4.5.0 | 图像处理 |
| Pillow | >=8.0.0 | 图像操作 |
| numpy | >=1.20.0 | 数值计算 |
| pywin32 | >=300 | Windows API |
