## 2. 函数设计思路

### 2.1 函数命名规范

```python
# 推荐命名方式
def 任务名称(hwnd, 参数1: 类型 = 默认值, 参数2: 类型 = 默认值):
    """
    任务描述
    
    参数：
        hwnd: 窗口句柄
        参数1: 参数说明
        参数2: 参数说明
    """
    pass
```

### 2.2 参数设计原则

| 原则 | 说明 |
|------|------|
| **必选参数** | `hwnd` 窗口句柄，所有任务函数必须包含 |
| **可选参数** | 带默认值，用户未配置时使用默认值 |
| **类型注解** | 明确参数类型，便于代码维护 |
| **参数命名** | 与配置项 `name` 字段保持一致 |

### 2.3 华山论剑1v1 设计

### 5.3 配置字段类型说明

| 类型 | 说明 | 必填字段 | 示例 |
|------|------|----------|------|
| `number` | 数字输入框 | `default` | `{"name": "count", "type": "number", "default": 1, "min": 1, "max": 10}` |
| `checkbox` | 复选框 | `default` | `{"name": "quick_exit", "type": "checkbox", "label": "秒退", "default": True}` |
| `dropdown` | 下拉选择框 | `options`, `default` | `{"name": "choice", "type": "dropdown", "options": ["A", "B"], "default": "A"}` |
| `text` | 文本输入框 | `default` | `{"name": "name", "type": "text", "default": ""}` |
| `row` | 行布局容器 | `items` | `{"name": "row1", "type": "row", "items": [...]}` |
| `group` | 分组容器 | `label`, `fields` | `{"name": "group1", "type": "group", "label": "分组", "fields": [...]}` |
| `label` | 静态标签 | `text` 或 `image` | `{"name": "hint", "type": "label", "text": "提示文字"}` |

### 5.4 嵌套约束

```
fields[]
├── 基础控件 (number, checkbox, dropdown, text)
├── label (静态标签)
├── row (行布局)
│   └── items[基础控件, label] ✓
│       └── row, group ✗ (禁止)
└── group (分组容器)
    └── fields[基础控件, label, row] ✓
        └── group ✗ (禁止)
```

## 8. 异常处理机制

### 8.1 任务函数中的异常处理

```python
def 华山论剑1v1(hwnd, count: int = 1, quick_exit: bool = True):
    """华山论剑1v1任务"""
    logger.info(f"开始执行华山论剑1v1任务")
    
    for i in range(count):
        try:
            # 任务逻辑
            
        except TaskStoppedException:
            # 用户中止任务
            logger.warning("任务被中止")
            raise  # 必须向上抛出，通知执行器
            
        except InvalidWindowHandleException:
            # 窗口句柄失效
            logger.error("窗口句柄失效")
            raise  # 必须向上抛出，触发重新绑定
            
        except Exception as e:
            # 其他异常
            logger.error(f"任务执行出错: {e}")
            # 可以选择继续或抛出
```

### 8.2 执行器中的异常处理

```python
# src/ui/main_window.py 中的执行循环
try:
    if task_name in logic_map:
        task_func = logic_map[task_name]
        params = self.task_params.get(task_name, {})
        
        # 参数传递和执行
        # ...
        
except ContextExpiredException:
    # 上下文失效（暂停超时）
    self.logger.warning(f"任务 [{task_name}] 上下文失效")
    reset_game_state(self.hwnd)
    
except InvalidWindowHandleException as e:
    # 窗口句柄失效
    self.logger.error(f"{str(e)}，请重新绑定窗口")
    break  # 终止执行
    
except TaskStoppedException:
    # 用户中止
    self.logger.warning("任务被用户中止")
    
except Exception as e:
    # 其他异常
    self.logger.error(f"任务执行错误: {str(e)}")
```

### 8.3 异常类型说明

| 异常类型 | 说明 | 处理方式 |
|----------|------|----------|
| `TaskStoppedException` | 用户中止任务 | 向上抛出，终止执行 |
| `InvalidWindowHandleException` | 窗口句柄失效 | 向上抛出，提示重新绑定 |
| `ContextExpiredException` | 暂停超时导致上下文失效 | 重置游戏状态，继续执行 |
| `Exception` | 其他未知异常 | 记录日志，继续或终止 |

## 附录B: 常见问题

### Q1: 参数值获取不到？

**检查项：**
1. 配置项的 `name` 字段与函数参数名是否一致
2. 参数传递逻辑是否正确添加
3. `params.get()` 的默认值是否正确

### Q2: UI控件不显示？

**检查项：**
1. 任务是否添加到 `daily_tasks` 列表
2. 配置定义是否添加到 `task_config_definitions`
3. 配置格式是否符合规范

### Q3: 任务执行时参数错误？

**检查项：**
